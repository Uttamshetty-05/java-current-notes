# Java Current Notes

Public notes and small Java samples for modern Java, the JVM, Spring, and Java + AI.

This repository is meant as a recruiter-friendly snapshot of topics that matter in 2026:

- Java LTS versions and the six-month release cadence
- Virtual threads, records, and sealed types
- Streams and everyday data processing
- Spring Boot 3 / Jakarta EE naming
- Calling LLMs from Java (Spring AI, LangChain4j)

Run any `.java` file under `src/` with JDK 21+:

```bash
java src/VirtualThreadDemo.java
```
